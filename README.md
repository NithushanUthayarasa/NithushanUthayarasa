## Selected projects

### ContextIQ — RAG-Powered Intelligence System

Built a multi-document retrieval system using Gemini embeddings and ChromaDB. It combines semantic search with BM25 and reciprocal rank fusion, then supports TF-IDF reranking, parent-child retrieval, context compression, page citations, retrieval inspection, and quantitative evaluation.

**Focus:** Retrieval quality, grounded answers, evaluation

[Repository](https://github.com/NithushanUthayarasa/ContextIQ-RAG-System) · [Live application](https://contextiq-ai-rag.streamlit.app/)

### Automated Manufacturing Inventory Coordinator

Contributed to a team-built manufacturing platform with an ASP.NET Core backend, React and Flutter interfaces, and a FastAPI/LangGraph service. The workflow includes validation and safety checks, inventory recommendations, defect management, quarantine, and audit history.

**Focus:** Multi-agent workflows, full-stack integration, operational safety

[Team repository](https://github.com/ChandranSukirthan/Automated-Manufacturing-Inventory-Coordinator)

### Garbage Image Classification

Developed a CNN transfer learning pipeline for 10 waste categories using more than 20,000 images. The work covers preprocessing, augmentation, model evaluation, and computer vision; the reported test accuracy is **88.6%**.

**Focus:** Deep learning, transfer learning, classification

[Repository](https://github.com/NithushanUthayarasa/SmartWaste-Image-Classification-CNN)

### Cyber Threats & Financial Loss Prediction

Built a machine learning comparison pipeline using Random Forest, CatBoost, XGBoost, LightGBM, and Extra Trees. The workflow includes hyperparameter tuning, cross-validation, evaluation metrics, and model selection.

**Focus:** Model comparison, validation, predictive analytics

[Repository](https://github.com/NithushanUthayarasa/CyberThreat-Financial-Loss-Prediction-ML)
